# wrdn Examples

This directory contains examples that demonstrate the capability-based security model of `wrdn`. 

`wrdn` is a security tool designed to eradicate supply chain attacks in WebAssembly component execution by bundling a virtualizer (which enforces granular Cedar policies) directly with the guest Wasm module.

## Structure

Each example is self-contained and demonstrates a specific security posture:

- **01-telemetry-allow-all**: A completely open policy (`permit(principal, action, resource);`). The guest is allowed to perform any action, but we still log (audit) every capability request.
- **02-telemetry-deny-all**: A strictly closed policy (`forbid(principal, action, resource);`). All capability requests (like network access or file system access) are denied by the virtualizer before they even reach the Node.js host.
- **03-telemetry-granular**: A realistic, restrictive policy. It permits only specific hostnames (`api.github.com`), IP addresses (`1.1.1.1`), and file paths (`allowed.txt`). All other requests are denied.

Inside each example directory, you will find:
- `policy.cedar`: The Cedar policy file defining the permissions.
- `guest.wasm`: The WebAssembly module containing the application logic.
- `index.js`: The Node.js entry point generated by `wrdn install`.
- `output.log`: The captured output from running the test, including the Virtualizer's Audit logs.

## How to Run

To run the examples locally, you can use the provided End-to-End test script from the root of the repository:

```bash
./run_e2e_tests.sh
```

This script will:
1. Build the dummy guest application from `examples/guest-app/`.
2. Copy the resulting `guest.wasm` into each example directory.
3. Run `wrdn install file://$(pwd)/guest.wasm` inside each directory.
4. Execute the transpiled module using `node --experimental-wasm-jspi index.js`.
5. Verify the output matches the expected security policy results.

### Manual Execution

If you wish to run a specific example manually:

1. Navigate to the example directory:
   ```bash
   cd examples/03-telemetry-granular
   ```
2. Run the `wrdn` installation to bundle the virtualizer and transpile the WASM:
   ```bash
   cargo run --bin wrdn -- install "file://$(pwd)/guest.wasm"
   ```
3. Run the resulting `index.js` file with Node.js (requires the JSPI flag for asynchronous WASI capabilities):
   ```bash
   node --experimental-wasm-jspi index.js
   ```
